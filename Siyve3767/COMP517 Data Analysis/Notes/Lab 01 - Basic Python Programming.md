## Objectives
- Develop essential data analysis skills: use Jupyter Notebook, Python built-in arithmetic operators, methods, and functions

## Setup
- Python 3 + **Anaconda** distribution (bundles Jupyter Notebook + data science packages)
- **Jupyter Notebook**: open-source web app by Project Jupyter; core languages Julia, Python, R; ships with the IPython kernel
- Check Python: run `python3` in the command line; follow the installation PDF if missing

## Tips and advice
1. Jupyter's directory works like a Windows directory - file changes are reflected
2. Type code yourself - copying can produce errors like `SyntaxError: invalid character` (U+2018)
3. `%whos` lists variables in the kernel (debugging)
4. Use the interrupt button if the kernel hangs

## Getting started
- Launch Jupyter via the Anaconda shortcut; browse to your folder; click New > Python 3 to create a `.ipynb` notebook
- First program: `print('Hello World!')` in an input cell, then Run
- Escape sequences: `\n` newline; raw strings `r'...'` (question: what happens without the `r`?)
- Basic arithmetic operators, Python built-in methods/functions
