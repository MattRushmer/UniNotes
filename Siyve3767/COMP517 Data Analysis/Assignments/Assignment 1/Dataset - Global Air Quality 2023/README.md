# Global Air Quality 2023 — Messy Version  
**Derived from**: “Global Air Quality Dataset” by WAQI786 on Kaggle (https://www.kaggle.com/datasets/waqi786/global-air-quality-dataset)  
**Created by**: Coffxc12

## Purpose  
This dataset is a modified (“messy”) version of the original AQI data, crafted for use in data-cleaning, de-duplication, anomaly detection, feature engineering, and robust machine-learning modelling in noisy-data settings.

## Modifications (AI-assisted)  
- Random missing values randomly injected in multiple columns  
- Duplicated and near-duplicate rows added  
- Noisy/outlier AQI values and inconsistent text formatting (typos, spacing issues)  
- Minor timestamp/location edits to simulate measurement/collection errors  
- Shuffled rows; inconsistent case/spacing for categorical fields
