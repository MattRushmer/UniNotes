## Vault conventions
- **One folder per course** — code-first names (`COMP504 Networks`), with `Lectures/`, `Labs/`, `Tutorials/`, `Exam Prep/`, `Reference/`, `Notes/` subfolders.
- **Each course folder starts with `Index.md`** — open it to see every file in that course (Obsidian can't search inside slides/PDFs, so the index is the entry point).
- **Files** — `Week NN - Topic.ext` or `ChNN - Topic.ext`.
- **Your own notes** — put markdown notes in the `Notes/` (or `My Notes/`) subfolder of the relevant course.
- **Tags** — course tag (`#comp504` `#comp507` `#comp517` `#math503`) + topic tags like `#subnetting`, `#exam-prep`.
- **Links** — written relative to the vault root (the folder this note lives in, where `.obsidian` is).
