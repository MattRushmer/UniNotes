# 📥 Inbox

**Drop new course files here.** Then tell the assistant to "process the inbox" — it will sort them into the right course folder, write/update notes with links, and research new topics (you approve the plan before anything moves).

**This folder and this README are permanent** — never delete them, even after processing. The folder stays at the vault root so it's always ready for the next batch of files.
